# AgriNexus

Interoperable AI-powered agricultural intelligence for climate-resilient farming across BRICS nations.

## Status

🚧 In active development

## Architecture

- Next.js frontend
- FastAPI backend
- PostgreSQL + PostGIS
- Gemini AI
- Google geospatial services
- Weather and agricultural datasets

## Core capabilities

- Localized agro-advisories
- Crop disease diagnosis
- Regenerative agriculture recommendations
- Multilingual / voice delivery
- Cross-border agricultural intelligence
